## Lambda Expressions and Algorithms Course

#### This project contains a cpp implementation for solving a user data problem. We are given users, roles and permissions. Each user can have multiple roles and each role has permissions. Based on the template of a permission: ["read", "write", "execute", "deny"] we need to output what permissions does the user have for the given queries.

The conceptual algorithm is based mostly on efficiently manipulating the data we get from input and easily access the information we use in order to decide the permissions and output them. In other words, the entire theoretical structure lies under a *greedy* approach that forces the developer to design a well conceived architecture which helps with building the solution easier.
